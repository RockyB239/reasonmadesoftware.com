# reasonmadesoftware.com

Public website for **Reasonmade**, including product information, support contact information, and public privacy policies.

The site is intentionally static and dependency-free. GitHub Pages publishes the repository, with `reasonmadesoftware.com` as the custom domain.

## Current public pages

- `/` — Reasonmade home
- `/privacy/before-i-touch-it/` — Before I Touch It privacy policy

Public support: **support@reasonmadesoftware.com**
